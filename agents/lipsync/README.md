# LipSync Agent

Animates a synthetic portrait to speak a narration with phoneme-accurate sync.

> **v1 default:** SadTalker (`LIPSYNC_BACKEND=sadtalker`).
> **Provider/adapter pattern** — the orchestrator never imports a concrete provider. The agent resolves the backend at startup from env via `core/registry.py`.

See [`docs/architecture/lipsync-adapter.md`](../../docs/architecture/lipsync-adapter.md) for the full contract.

## Inputs

- `portrait_path` — MinIO URI to a synthetic portrait (PNG, generated by the Face agent and identity-guard cleared).
- `audio_path` — MinIO URI to `narration.wav` (48 kHz mono).
- `phonemes_path` — MinIO URI to phoneme/viseme timestamps emitted by the Voice agent.
- `fps` — target framerate (default 25).
- `seed` — reproducibility seed.
- `compliance_token` — short-lived JWT issued by the Compliance Officer; verified before any compute.
- `params` — provider-specific knobs (kept narrow and validated per provider).

## Outputs

- `talking_head.mp4` — MinIO URI.
- `sync_score` — SyncNet-style confidence in [0, 1].
- `model_version`, `seed_used`, `duration_ms`, `frame_count`.

## Hard rules

- Rejects any request without a valid `compliance_token`. No bypass flag exists.
- Refuses to start if `required_assets()` are missing or hashes don't match — see [`docs/runbooks/model-management.md`](../../docs/runbooks/model-management.md).
- Never auto-downloads weights unless `ALLOW_MODEL_AUTODOWNLOAD=true` (off by default).
